CASINO CRAZE — PHONE INSTALL PACKAGE

This is an installable Progressive Web App (PWA) package for Android phones.
It contains the Casino Craze offline game, web app manifest, service worker and icons.

TO INSTALL ON ANDROID
1. Publish the contents of this folder to an HTTPS static website (for example, a static hosting service).
2. Open the published HTTPS address in Chrome on your Android phone.
3. Open Chrome menu (three dots) and choose Install app or Add to Home screen.
4. Launch Casino Craze from the new home-screen icon.

NOTE
This package is not an APK. It installs as a web app from Chrome. A native APK requires an Android build service or Android development environment.

GAME CONTENT
40 cards (values 1–10 in four suits), four players, ten cards each, one human and three bots.
Last player to capture takes remaining table cards.
Scoring shown in the game: each Ace, 6 of Spades and 10 of Diamonds = 1 point; more than 20 captured cards = 2 bonus points.
